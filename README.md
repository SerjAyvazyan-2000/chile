# Салон красоты «Чили» — демо-сайт (LID-41)

Персональное демо на базе шаблона Mirelle. Санкт-Петербург, Синявинская ул., 6 · +7 (900) 632-57-57.

Сборка не нужна — открыть `index.html` или загрузить папку на хостинг (Vercel / GitHub Pages).
Весь контент — в `assets/js/config.js`.

## Убрано из шаблона

- Выдуманные отзывы, мастера (Алина Соколова и др.), цифры «8 лет / 12 мастеров / 4900 гостей», реквизиты ИП, e-mail, Instagram.
- **Блок «Мастера»** — скрыт: мастера есть в YCLIENTS (Оля Мосейкина, Лилия, Вероника, Виктория, Юлия, Оксана), но фото нет. Включить: `hide.masters: false` + заполнить `masters`.
- **Блок-слайдер (бывший «До / После»)** — включён, но сравнивает две реальные работы колористов салона («Медь» / «Неон»): парных снимков «до/после» одной работы в источниках нет, а по ТЗ выдавать разные работы за «до/после» нельзя. Когда салон пришлёт пару — заменить `beforeAfter.before/after` и подписи на «До» / «После».

## Материалы на согласование перед публикацией

1. **Логотип** — вырезан с обложки ВК, лучше попросить у салона исходник (SVG/PNG).
2. **Фото с людьми** (`copper.jpg`, `guest.jpg`) — нужно согласие гостей на использование на сайте.
3. **Фото, загруженные посетителями в 2ГИС** (`nails-pink.jpg`, `pedicure.jpg`) — авторы не салон, согласовать или заменить.
4. Все фото — с водяным знаком 2ГИС; для боевого сайта попросить оригиналы.
5. **Отзывы из 2ГИС** — показаны имена и сокращённые тексты, согласовать с салоном.
6. **Адрес**: в 2ГИС, YCLIENTS и ТЗ — Синявинская ул., 6, а во ВКонтакте указан Большеохтинский пр., 31. Уточнить у салона.
7. **Цены во ВКонтакте устарели** (ниже, чем в YCLIENTS) — на сайте цены из YCLIENTS, а ВК стоит обновить.
8. Наращивание ресниц упомянуто в отзыве, но в онлайн-записи его нет — в прайс не добавлено.

Не взяты в демо: фото с ребёнком (стрижка каре, косички) — без согласия родителей использовать нельзя.

## Как поменять

- Цены/услуги: `services` в `config.js` (`price` — от, `min` — минуты).
- Ссылка записи: `booking.url`.
- Заявки на сервер вместо WhatsApp: `form.endpoint`.
